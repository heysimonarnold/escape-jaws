# Escape Jaws

![Escape Jaws](./public/og-image.png)

Url: [https://heysimonarnold.github.io/escape-jaws/](https://heysimonarnold.github.io/escape-jaws/)

Escape Jaws est un jeu sonore où l’ouïe devient instinct de survie. Guidé par des signaux invisibles, tentez d’échapper au requin mythique, une présence tapie dans l’ombre, prête à vous dévorez au moindre faux pas.
